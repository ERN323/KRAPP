# KRAPP — Karting Racing App (PWA)

A Progressive Web Application for organizing karting groups/leagues, tracking race history, and importing CSV race results.

## Features (Step 1: Homescreen & Driver Profile)
- **Top Bar**: Displays driver `@USERNAME` and notification bell button.
- **Central Avatar & Profile Editor**: Tap the central circle to edit:
  - `@Username`, **Name**, **Surname**
  - **Driver Weight (kg)** & **Bio**
  - **Custom Avatar Upload** or choose from **6 Built-in Racing Helmet Icons**
- **Bottom Action Cards**: Quick thumb access to **RACE HISTORY** and **MY LEAGUES**.
- **Installable PWA**: Configured with `vite-plugin-pwa` manifest and service worker.

## Local Development

```bash
npm install
npm run dev
```
